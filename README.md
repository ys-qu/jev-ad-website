# Jev with Foresight

Project page for the paper *Jev with Foresight: Safe Language-Guided Autonomous Driving via a Language World Model*
(Yansong Qu, Jiancong Chen, Samuel Labi, Purdue University).

The page is a single static `index.html` with its figures and video in `static/`; it is served with GitHub Pages
(Settings -> Pages -> Deploy from branch `main`, folder `/ (root)`).
